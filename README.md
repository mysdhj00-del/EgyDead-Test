# EgyDead-Test

Test repository for a Gemini-generated CloudStream extension. Not the real repo.

## Add to CloudStream

Settings → Extensions → Add Repository → paste this URL:

```
https://raw.githubusercontent.com/mysdhj00-del/EgyDead-Test/builds/repo.json
```

Pushing to `main` rebuilds all plugins automatically (GitHub Actions) and
publishes them to the `builds` branch.
